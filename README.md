# Abhishek Saste — AWS & DevOps Portfolio

A responsive, animated portfolio inspired by the clean structure and interaction style of modern cloud/engineering portfolios, customized for Abhishek Saste.

## Highlights
- Professional profile photo in the hero
- Animated AWS/DevOps visual treatment
- Responsive navigation and smooth scroll
- Scroll reveal, typewriter, floating badges and network background
- AWS, DevOps, Linux, networking and scripting sections
- Featured projects with direct GitHub links
- Resume download
- Education, certification and contact information
